# Generated screenshots

These PNG files are generated by [the Visual screenshots GitHub Actions workflow](../../.github/workflows/screenshots.yml).

All images are captured at 1920×1080 from the Godot project running at its 320×180 virtual resolution.

- `demo.png`: demo without CRT
- `demo_crt.png`: demo with CRT
- `pixel-test.png`: pixel-grid test without CRT
- `pixel-test_crt.png`: pixel-grid test with CRT

The workflow refreshes these files on pushes to `main`. Changes to this directory do not trigger another screenshot run.
